# CoSperta.AI — Propuesta Técnica

Propuesta de servicios de ingeniería de software e inteligencia artificial para el proyecto CoSperta.AI de CoRegistros, S.L.U.

## Proyecto

CoSperta.AI es una plataforma de consultoría energética digital que analiza facturas y contratos de energía, compara ofertas del mercado y recomienda la opción óptima mediante IA explicable.
