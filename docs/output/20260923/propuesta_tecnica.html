1. Comprensión del Proyecto

CoSperta.AI es una plataforma de consultoría energética digital, independiente y automatizada que analiza facturas y contratos de energía, compara las ofertas del mercado y recomienda la opción óptima mediante inteligencia artificial explicable. Está dirigida a hogares, pymes y asesorías energéticas.

Enfoque técnico por paquete de trabajo

PT01 — Arquitectura

  • Microservicios con FastAPI, stack Python
  • PaddleOCR, LangChain, ClickHouse
  • Seguridad: AES-256, TLS 1.3

PT02 — Motor IA (Core)

  • ML consumo: clustering, predicción, contextual bandits
  • NLP contractual: extracción de cláusulas
  • Fuentes CNMC, OMIE, REE-ESIOS + SHAP

PT03 — OCR de Facturas

  • PaddleOCR + LayoutLMv3
  • Pipeline: preprocesado → detección → reconocimiento → postprocesado LLM

PT04 — Dashboard BI

  • APIs personalización y alertas
  • Vista agregada asesorías, ClickHouse + Redis

PT05 — Chatbot

  • LangChain + RAG + WhatsApp Business API
  • NLP entrenado en dominio energético

PT06-PT07 — Pruebas y Despliegue

  • Planes integrales + optimización modelos
  • Despliegue producción + documentación

2. Metodología de Trabajo y Control de Calidad

Diferenciador clave — Enjambre de Agentes IA: Killia no aplica desarrollo tradicional. Utilizamos un enjambre de agentes IA (OpenCode + Hermes) que ejecutan tareas de código, tests y documentación en paralelo, mientras Miquel Colomer supervisa la arquitectura, toma decisiones de diseño y asegura la calidad. Resultado: 3-5x más rápido que desarrollo tradicional, con reducción de costes del 40-50% manteniendo estándares de calidad enterprise.

ómo funciona el enjambre

Agentes de Código

Generan implementación Python/FastAPI siguiendo especificaciones detalladas. Crean tests unitarios automáticos. Siguen patrones de código predefinidos y buenas prácticas.

Agentes de Validación

Ejecutan suites de tests, detectan regresiones, revisan cobertura de código. Mantienen CI continuo con integración automática.

Supervisión Humana

Miquel Colomer decide arquitectura, revisa calidad del código resultante, asegura coherencia con el proyecto global y toma decisiones de diseño críticas.

Ventajas cuantificables: Un solo desarrollador experimentado, potenciado con enjambre de agentes IA, alcanza la productividad de un equipo de 3-4 ingenieros. Los agentes ejecutan código repetitivo, generan tests, documentan y revisan, mientras el humano se enfoca en decisiones de arquitectura y diseño de negocio.

Control de calidad

  • Scrum: Sprints 2-4 semanas, backlog compartido con CoRegistros
  • TDD + CI/CD: Tests antes que código, integración continua automatizada
  • Git: Control de versiones, revisión de código por pares (agente + humano)
  • Validación modelos: Métricas documentadas (precisión, recall, F1), validación cruzada

Seguridad

  • RGPD desde el diseño, anonimización datos personales
  • AES-256 reposo, TLS 1.3 tránsito, gestión segura de secretos
  • Control accesos por roles, auditabilidad completa de decisiones IA
