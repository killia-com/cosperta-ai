1. Comprensión del Proyecto

CoSperta.AI es una plataforma de consultoría energética digital que analiza facturas y contratos de energía, compara ofertas del mercado y recomienda la opción óptima mediante IA explicable. Está dirigida a hogares, pymes y asesorías energéticas.

PT01 — Arquitectura

  • Microservicios con FastAPI, stack Python
  • PaddleOCR, LangChain, ClickHouse
  • Seguridad: AES-256, TLS 1.3

PT02 — Motor IA (Core)

  • ML consumo (scikit-learn, SHAP)
  • NLP contractual (Transformers)
  • Fuentes CNMC, OMIE, REE-ESIOS

PT03 — OCR de Facturas

  • PaddleOCR + LayoutLMv3
  • Pipeline automatizado + LLM

PT04 — Dashboard BI

  • APIs personalización y alertas
  • ClickHouse + Redis

PT05 — Chatbot

  • LangChain + RAG + WhatsApp API
  • NLP dominio energético

PT06-PT07 — Pruebas y Despliegue

  • Planes integrales + optimización
  • Despliegue en producción
