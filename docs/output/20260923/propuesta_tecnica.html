1. Comprensión del Proyecto

CoSperta.AI es una plataforma de consultoría energética digital que analiza facturas y contratos de energía, compara ofertas del mercado y recomienda la opción óptima mediante IA explicable. Está dirigida a hogares, pymes y asesorías energéticas.

Enfoque técnico por paquete de trabajo

PT01 — Arquitectura

  • Diseño de microservicios con FastAPI
  • Selección de stack: Python, PaddleOCR, LangChain, ClickHouse
  • Seguridad desde el diseño (AES-256, TLS 1.3)

PT02 — Motor IA (Core)

  • Modelos ML de análisis de consumo (scikit-learn, SHAP)
  • NLP para análisis contractual (Transformers)
  • Integración fuentes CNMC, OMIE, REE-ESIOS

PT03 — OCR de Facturas

  • OCR profundo: PaddleOCR + LayoutLMv3
  • Pipeline de extracción automatizado
  • Postprocesado semántico con LLM

PT04 — Dashboard BI (Backend)

  • APIs de personalización y alertas
  • Agregación de datos para asesorías
  • ClickHouse analítico + Redis caché

PT05 — Chatbot Inteligente

  • Motor conversacional (LangChain + RAG)
  • Integración WhatsApp Business API
  • NLP entrenado en dominio energético

PT06-PT07 — Pruebas y Despliegue

  • Planes de prueba integrales (funcional, rendimiento, seguridad)
  • Optimización de modelos (ajuste fino)
  • Despliegue en producción y puesta en marcha

2. Metodología de Trabajo

Diferenciador clave: Killia no aplica desarrollo tradicional. Utilizamos un enjambre de agentes IA (OpenCode + Hermes) que ejecutan tareas de código, tests y documentación en paralelo, mientras Miquel Colomer supervisa la arquitectura, toma decisiones de diseño y asegura la calidad.

Cómo funciona el enjambre

Agentes de Código

Generan implementación Python/FastAPI siguiendo especificaciones. Tests unitarios automáticos.

Agentes de Validación

Ejecutan tests, detectan regresiones, revisan cobertura. CI continuo.

Supervisión Humana

Miquel decide arquitectura, revisa calidad, asegura coherencia con el proyecto.

Ventajas: Velocidad 3-5x superior al desarrollo tradicional. Consistencia en patrones de código. Reducción de costes del 40-50% manteniendo calidad.

Control de calidad

  • Scrum con sprints de 2-4 semanas, backlog compartido con CoRegistros
  • TDD (desarrollo orientado a pruebas) + integración continua (CI)
  • Control de versiones con Git y revisión de código por pares
  • Validación de modelos con conjuntos de prueba representativos y métricas documentadas

Seguridad y privacidad

  • Cumplimiento RGPD desde el diseño
  • Cifrado AES-256 en reposo y TLS 1.3 en tránsito
  • Anonimización y vectorización de datos personales
  • Gestión segura de secretos y control de accesos
